## 📂 Labs Included

### Lab 1 — Logistic Regression

Topics covered:

* Introduction to Machine Learning
* Logistic Regression
* Binary Classification
* Sigmoid Function
* Model Training
* Prediction
* Performance Evaluation

**Assignment**

Develop a Heart Disease Classification model using Logistic Regression on the provided dataset.

---

### Lab 2 — Linear Regression

Topics covered:

* Linear Regression
* Cost Function
* Gradient Descent
* Model Optimization
* Data Visualization
* Multiple Linear Regression Concepts

Implement a Linear Regression model using the provided housing dataset.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/pankajmehta07/Artificial-Intelligence---LabWorks---BEI.git
cd Artificial-Intelligence---LabWorks---BEI
```

### Create a virtual environment (optional)

```bash
python -m venv .venv
```

Activate it:

**Windows**

```bash
.venv\Scripts\activate
```

**Linux/macOS**

```bash
source .venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Notebooks

Launch Jupyter Notebook:

```bash
jupyter notebook
```

or

```bash
jupyter lab
```

Open the desired notebook from the corresponding lab folder.
